- На VPS работает Docker-стек Itsaplan за Caddy. Веб-приложение и API доступны

- CORS разрешён только для домена веб-приложения.

## Telegram-уведомления

- Создан Telegram-бот; его токен хранится вне репозитория в локальном защищённом
  файле.
- В Itsaplan уже есть штатный механизм доставки: worker отправляет уведомления
  из очереди в Telegram и повторяет временно неудачные попытки.
- Штатные Telegram-уведомления предназначены для назначения задач, упоминаний,
  комментариев в отслеживаемых задачах и изменений их статусов.
- Настройка требует владельца проекта или экземпляра Itsaplan: текущая роль
  Codex `Member` не позволяет управлять учётными данными уведомлений.
- Ежедневная сводка дедлайнов реализована в существующих worker и очереди
  уведомлений. В 10:00 по Стамбулу каждый связанный Telegram-аккаунт получает
  одно сообщение со своими незавершёнными просроченными задачами и задачами со
  сроком на сегодня по всем доступным проектам.
- Уникальное ограничение в базе данных исключает повторную сводку в тот же день
  после перезапуска worker. Для функции не нужны отдельный скрипт, контейнер или
  языковая модель.
