# Уведомления и интеграции

Этот файл фиксирует текущее состояние уведомлений и интеграций Itsaplan. Секреты,
API-ключи, токены и идентификаторы чатов здесь не хранятся.

## Telegram

### Бот

- Telegram-бот создан.
- Его токен хранится только в локальном защищённом файле вне репозитория.
- Бот ещё нужно указать в настройках экземпляра Itsaplan. Для этого требуются
  права владельца экземпляра.

### Штатные уведомления Itsaplan

Itsaplan уже умеет отправлять сообщения через встроенную очередь уведомлений и
worker. Временная ошибка доставки приводит к повторной попытке.

После подключения бота в интерфейсе следует включить для Denis в нужных проектах:

- назначение задачи;
- упоминание;
- комментарий в отслеживаемой задаче;
- изменение статуса отслеживаемой задачи.

Один Telegram-аккаунт подключается к профилю Itsaplan через одноразовую ссылку.
Идентификатор чата вручную не вводится и не хранится в документации.

### Ежедневная сводка дедлайнов

Функция реализована в исходном коде и станет доступна после развёртывания новой
версии на VPS.

- Время отправки: 10:00 по Стамбулу.
- Получатель: каждый пользователь, который связал Telegram с профилем Itsaplan.
- Содержание: одна сводка по незавершённым просроченным задачам и задачам со
  сроком на сегодня во всех проектах, доступных получателю.
- Дубликаты: база данных не позволяет создать больше одной сводки для одного
  пользователя за одну дату, в том числе после перезапуска worker.
- Реализация использует существующие worker и очередь уведомлений. Отдельный
  скрипт, контейнер, агент или языковая модель не нужны.

## MCP

- MCP включён для проекта `INFR`.
- Codex подключён отдельным профилем внешнего агента, поэтому его действия
  видны в истории от имени Codex.
- Claude Code подключён к тому же MCP и сейчас использует личный ключ Denis,
  поэтому его действия отображаются от имени Denis.
- Для нового агента создаётся отдельный профиль и API-ключ. Полная процедура
  описана в `personal-agent-convention.ru.md`.

## Каталог Tools

Каталог Tools — это набор дополнительных инструментов для внутренних агентов
Itsaplan. Он не подключён к Codex или Claude Code через MCP и не нужен для
штатной работы агентов с задачами.

Интеграции из каталога подключаются только под конкретную повторяющуюся задачу
и после отдельного согласования. Они могут требовать собственные учётные данные
и платный тариф поставщика.

## Что осталось сделать

1. Подключить Telegram-бота в настройках экземпляра Itsaplan.
2. Включить штатные события Telegram в настройках нужных проектов.
3. Развернуть новую версию Itsaplan на VPS.
4. Проверить доставку штатного уведомления и ежедневной сводки.
